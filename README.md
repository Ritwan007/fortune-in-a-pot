A make.fun entry for **Fortune in a Pot**. The program writes one line — a houseplant's fortune — to `/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```

The entry line (109 characters):

> You will get a bigger pot this spring, little fern — and a keeper who waters you before the droop, not after.
